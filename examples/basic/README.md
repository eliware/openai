# Basic example

[Root README](../../README.md)

## Prerequisites

The parent directory contains runnable HTTP and WebSocket examples. Set
`OPENAI_API_KEY` in the environment, then run one of those `.mjs` files with
Node.js 26. Never put credentials in example source files.

## Usage

From the repository root, run `node examples/http.mjs` or
`node examples/websocket.mjs`.

## Expected results

The example prints the returned response or streamed events.
