# Documentation

`@eliware/openai` is a thin ESM and TypeScript wrapper around the official
OpenAI Node.js SDK.

- [Configuration](configuration.md)
- [Transports](transports.md)
- [Pricing](pricing.md)

Audience: package users. Prerequisites: a supported runtime and an
appropriately scoped provider configuration. Expected result: the wrapper
performs the documented request workflow without exposing credentials.
