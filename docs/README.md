# Documentation

Use these guides to install, configure, and use `@eliware/openai`.

## Guides

- Read [Configuration](configuration.md) to set an API key, SDK options, or a logger.
- Read [API](api.md) to create clients, send requests, process events, and use exported types.
- Read [Transports](transports.md) to select HTTP or WebSocket.
- Read [Pricing](pricing.md) to estimate supported model costs.
- Read [Troubleshooting](troubleshooting.md) to resolve common errors.

Use Node.js 26 or later. Install the package with `npm install @eliware/openai`.
