# Overview

The package provides a thin ESM-first wrapper around the official OpenAI
Node.js SDK. HTTP is the default Responses transport; WebSocket support is
explicitly selected with `transport: 'websocket'`. Public exports,
declarations, README examples, and tests are kept synchronized.
